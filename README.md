# NEXO Fight Club

[Ver la landing](https://8b75e929-nexo-fight-club.netlify.app/)

Proyecto conceptual de una escuela de boxeo en Buenos Aires. Diseño UX/UI, contenido y dirección visual por Victoria Piatigorsky · Studio V.

## El problema de diseño

¿Cómo transmitir la exigencia y el oficio del boxeo sin intimidar a quien nunca entrenó? La landing establece una propuesta desde el primer pantallazo y ofrece tres recorridos según el objetivo de quien llega: empezar de cero, entrenar con constancia o competir.

## Decisiones de diseño

- **Dirección visual.** Fotografía monocromática, títulos condensados, bordes rectos y rojo para destacar acciones.
- **Contenido.** El método muestra una progresión y la grilla permite ubicar los turnos iniciales de un vistazo.
- **Interacción.** El botón «Probar una clase» permite elegir un turno ilustrativo y ver la confirmación de la simulación.
- **Adaptación.** Menú móvil, tabla con desplazamiento horizontal, controles accesibles con teclado y animación de entrada sujeta a la preferencia de movimiento del dispositivo.

La ubicación y los horarios son ilustrativos. La demo no toma datos personales ni genera reservas reales. Es un ejercicio de diseño y no presenta resultados comerciales medidos.

## Despliegue

Sitio estático de HTML, CSS y JavaScript. Los archivos se publican desde la raíz del repo en Netlify. Las imágenes están incluidas y las tipografías de Google Fonts tienen alternativas locales.
